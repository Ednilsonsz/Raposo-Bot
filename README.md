# Raposo-Bot

Código do Raposo Bot V3.86 R12.

## Instalação no Windows

1. Instale as dependências com `python -m pip install -r app/requirements.txt`.
2. Copie `config/config.example.json` para `config/config.json` e `config/config_v386_release.json` e ajuste as configurações locais.
3. Inicie com `scripts/INICIAR_RAPOSO_R12.bat`.

Credenciais, configurações pessoais, backups, relatórios e bancos de dados ficam fora do Git. As credenciais devem ser cadastradas pela interface do aplicativo.

Veja a documentação na pasta `docs/`.
